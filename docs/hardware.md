# 부품·배선 결정표

기준: NUCLEO-F446RE. 센서, 펌프, 방향 모터 모델은 사용자 확인 기준 **미정**입니다. 모든 MCU 핀·커넥터·AF·타이머 값은 부품 데이터시트 및 실제 보드 리비전 확인 후 확정합니다.

| 장치/신호 | 모델 | MCU 핀 / CN 위치 | 인터페이스·전기 조건 | 담당·결정 자료 |
| --- | --- | --- | --- | --- |
| 화재 감지 센서 | 미정 | 미정 | ADC/GPIO/I2C 등 미정, 출력 전압·논리 극성 확인 | 감지 A |
| 방향 추정용 입력 | 센서 배열/스캔/별도 입력 중 미정 | 미정 | 단일 검출 신호만으로 각도를 생성하지 않음 | 감지 B |
| 방향 모터·드라이버 | 서보/스텝/DC 미정 | 미정 | PWM/STEP-DIR 등 미정, 기계 범위·홈·정지 정의 | 진화 A |
| 물 펌프·드라이버 | 미정 | 미정 | 정격/기동/정지 전류, ON 극성, 역기전력 대응 | 진화 B |
| 비상정지·리셋 입력 | 미정 | 미정 | 배선 방식, 풀업/풀다운, 디바운스, 전원 차단 경로 | 진화 B |
| PC UART 로그 | 연결 경로 미정 | 미정 | 제안 115200/8N1, 실제 인스턴스·연결 확정 필요 | 감지 A |
| 펌프·모터 전원 | 미정 | 해당 없음 | 구동 전압·전류·공통 GND/절연 설계 확정 | 진화 A/B |

MCU 핀으로 모터나 펌프 전원을 직접 공급하지 않습니다. 선정한 드라이버의 데이터시트 기준으로 전원·배선·보호 소자를 설계하고, 부팅 및 오류 시 출력 OFF를 하드웨어와 소프트웨어 양쪽에서 확인합니다. 액티브 LOW 드라이버의 OFF 값은 논리 `false`를 단순 GPIO LOW로 매핑해서는 안 됩니다.

## 장치별 결정 기록 양식

- 장치 / 모델 / 데이터시트 링크 / 보드 리비전:
- 공급 전압 / 소비·기동 전류 / 신호 전압 / 논리 극성:
- 인터페이스 / 주소 / 데이터 단위 / 응답시간 / 오류 검출 방법:
- MCU 핀 / CN 위치 / AF / 인스턴스 / TIM 채널 / 충돌 확인:
- 초기 출력 / 통신 실패 시 동작 / 물리적 정지 동작:
- 실측 / 측정 도구 / 사진·로그 / FR·MOD·TC / 검토자 / 날짜:

모터 위치 피드백 없이 일정 시간 대기하는 현재 로직은 조준 완료를 보증하지 않습니다. 엔코더/홈 센서 여부 또는 기구별 검증 가능한 대기시간을 결정하고 TC-103에서 실측합니다. 물 부족·공회전 방지나 구동 이상 검출 입력도 장치 선정 시 요구사항에 추가할지 결정합니다.

공식 확인 자료: [NUCLEO-F446RE 및 보드 문서](https://www.st.com/en/evaluation-tools/nucleo-f446re.html), [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html). 부품별 실제 데이터시트는 선정 후 추가합니다.
